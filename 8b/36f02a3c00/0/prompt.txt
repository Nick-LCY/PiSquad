**新增 `resolveTools` 辅助函数**（放在 `resolveSkillPaths` 函数后面）：
```typescript
/**
 * Resolve an agent's tool configuration to a concrete tool list.
 *
 * - If neither `tools` nor `toolsDeny` is set → returns undefined (all tools available)
 * - `tools` entries ending with `*` are expanded as prefix wildcards against `allToolNames`
 * - When `tools` is set → start from the whitelist, then filter out `toolsDeny`
 * - When only `toolsDeny` is set → start from all tools, filter out denied ones
 */
function resolveTools(
    agent: AgentConfig,
    allToolNames: string[],
): string[] | undefined {
    // Neither set → undefined (all tools)
    if (!agent.tools && !agent.toolsDeny) return undefined;

    let resolved: string[];

    if (agent.tools) {
        resolved = [];
        for (const tool of agent.tools) {
            if (tool.endsWith("*")) {
                const prefix = tool.slice(0, -1);
                // Match all tools starting with the prefix
                const matches = allToolNames.filter(t => t.startsWith(prefix));
                resolved.push(...matches);
            } else {
                resolved.push(tool);
            }
        }
        // Deduplicate (in case a wildcard matched an explicitly listed tool)
        resolved = [...new Set(resolved)];
    } else {
        // No whitelist, start from all tools
        resolved = [...allToolNames];
    }

    // Apply deny list
    if (agent.toolsDeny && agent.toolsDeny.length > 0) {
        resolved = resolved.filter(t => !agent.toolsDeny!.includes(t));
    }

    return resolved.length > 0 ? resolved : undefined;
}
```

Task: ## 任务：修复 subagent 扩展的 3 个 Critical 问题

### 背景
上一轮实现了 `tools_deny` 黑名单和 `tools` 通配符支持，但 reviewer 发现了 3 个必须修复的问题。

### 修复 1：空集回退漏洞（Critical）

**问题**：`resolveTools` 在 deny 把最终集清空时返回 `undefined`，导致调用方跳过 `--tools`，子进程得到全部工具。这是提权漏洞。

**修复**：
- `resolveTools` 的返回类型改为 `string[]`（不再返回 `undefined`）
- 调用方：当 `resolvedTools.length === 0` 时传 `--no-tools`（而非跳过 `--tools`）

### 修复 2：subagent 默认禁止递归委派（用户要求）

**问题**：任何 subagent 都可以通过 subagent 工具委派 worker（全权限），绕过权限限制。

**修复**：在 `resolveTools` 中，**始终**从 resolved 列表中过滤掉 `"subagent"` 工具。不需要在 agent frontmatter 中声明。这意味着所有通过 subagent 调用的 agent 都无法再调用 subagent。

### 修复 3：planner 不应有 bash（回归）

**问题**：planner 旧配置 `tools: read, grep, find, ls` 没有 `bash`，新配置 `tools_deny: write, edit` 反而给了它 bash。scout 和 reviewer 旧配置本来就有 bash，保持不变。

**修复**：`planner.md` 的 frontmatter 改为 `tools_deny: write, edit, bash`

#### `.pi/extensions/subagent/index.ts`

**`resolveTools` 函数** — 重写为以下逻辑：

```typescript
function resolveTools(
	agent: AgentConfig,
	allToolNames: string[],
): string[] {
	let resolved: string[];

	if (agent.tools) {
		// Whitelist with wildcard expansion
		resolved = [];
		for (const tool of agent.tools) {
			if (tool.endsWith("*")) {
				const prefix = tool.slice(0, -1);
				const matches = allToolNames.filter((t) => t.startsWith(prefix));
				resolved.push(...matches);
			} else {
				resolved.push(tool);
			}
		}
		// Deduplicate
		resolved = [...new Set(resolved)];
	} else {
		// No whitelist, start from all tools
		resolved = [...allToolNames];
	}

	// Apply explicit deny list from frontmatter
	if (agent.toolsDeny && agent.toolsDeny.length > 0) {
		resolved = resolved.filter((t) => !agent.toolsDeny!.includes(t));
	}

	// Always deny subagent to prevent recursive delegation
	resolved = resolved.filter((t) => t !== "subagent");

	return resolved;
}
```
