Task: ## 修复 src/lib/ui.ts 中 decideChannels 的两个 bug

先 `read src/lib/ui.ts` 确认现状，再做以下修复。

### bug 1（语义错误，必修）
`--without` 命令行分支当前返回 `withChannels(new Set())` = core only（entire 也被关掉）。**正确语义**：`--without` 的基准是「全部可选 channel」（即等价于 `--all` 的集合），减去排除项。例：`--without codegraph` 应返回 `{core:true, codegraph:false, entire:true}`。
- `PISQUAD_WITHOUT` 环境变量分支有完全相同的问题，同样修正。
- 修正方式：算出 exclude 集合后，返回 `{ core:true, codegraph: !exclude.has("codegraph"), entire: !exclude.has("entire") }`，并删掉当前算出却未使用的死代码变量。

### bug 2（缺冲突检测，必修）
- 命令行 `--with` 和 `--without` 同时给出时，应**抛错退出**（planner 设计要求），错误信息清晰，如 `Cannot combine --with and --without`。
- 环境变量 `PISQUAD_WITH` 和 `PISQUAD_WITHOUT` 同时给出时，同样抛错。

### 实现注意
- 保持现有优先级结构不变（`--all` > `--with` > `--without` > `--yes` > env.WITH > env.WITHOUT > interactive > core-only）
- 跨来源冲突（如命令行 `--with` + 环境变量 `PISQUAD_WITHOUT`）不必严格检测，命令行优先即可；但**同一来源内的重叠必须报错**
- **只改 `src/lib/ui.ts` 这一个文件**，不碰其它

### 验证（通过才 commit）
- `npx tsc --noEmit` exit 0
- `npm run build` exit 0
- 用 `npx tsx`（或临时脚本）快速验证几组 `decideChannels` 输入：
  - `{with:"codegraph"}` → `{core:true, codegraph:true, entire:false}`
  - `{without:"codegraph"}` → `{core:true, codegraph:false, entire:true}` ← 修复点
  - `{with:"codegraph", without:"entire"}` → 抛错 ← 修复点
  - `{all:true}` → 全 true
  - `{yes:true}` → core only

### commit（单独一次，只含 src/lib/ui.ts）
`fix(cli): correct --without channel semantics and detect with/without conflict`
