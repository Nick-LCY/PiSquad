Task: ## 任务：npm 包名改为 scoped `@nicklin/pisquad`

`npm publish` 被拒：`pisquad` 与已存在的 `pi-squad` 太相似（npm 相似性规则）。改用 scoped 包名 `@nicklin/pisquad`。

**铁律：只改「npm 包名」相关引用；命令名 `pisquad`（bin）保持不变。** `bin` 字段 key、`command -v pisquad`、所有 `pisquad install/upgrade/...` 命令调用都**不要动**。

### 先定位所有需改的引用
用 grep 找全：
```bash
grep -rn "pisquad@latest" --include="*.ts" --include="*.md" --include="*.json" --include="pisquad" .
grep -rn "npm i -g pisquad\|npm install -g pisquad\|npm i -g \"pisquad\|npx pisquad" --include="*.ts" --include="*.md" --include="*.json" --include="pisquad" .
```
把这些「npm 包名语境」的 `pisquad`（裸包名，非命令名）改为 `@nicklin/pisquad`。

1. **`package.json`**：
   - `"name": "pisquad"` → `"name": "@nicklin/pisquad"`

2. **根 `pisquad`（bash bootstrap）**：
   - `npx --yes pisquad@latest` → `npx --yes @nicklin/pisquad@latest`
   - `command -v pisquad` **不变**（bin 名仍是 pisquad）
3. **`src/upgrade/self.ts`**：
   - `npm install -g pisquad@latest`（或 `["install","-g","pisquad@latest",...]`）→ 改为 `@nicklin/pisquad@latest`
   - `which("pisquad")` 检测逻辑**不变**（检测的是 bin 名 pisquad，不受包名影响）
