```
Error: Dynamic require of "tty" is not supported
    at dist/bin.js:12
    at node_modules/yoctocolors-cjs/index.js (dist/bin.js:786)
```

根因：yoctocolors-cjs（CommonJS 包）被 tsup 内联进 ESM bundle，运行时它的 require("tty") 在 ESM 下失败。这个 CJS 依赖大概率是本次新增的 @inquirer/prompts 的 editor prompt（src/upgrade/decision-defaults.ts 里用了 inquirer 的 editor()）拉进来的传递依赖。注意：之前 install 命令也用 @inquirer/prompts 但能正常打包，是因为没用到 editor 子模块、tree-shaking 去掉了 CJS 依赖链；现在 editor 被实际引用，CJS 依赖被拉进 ESM bundle 导致崩溃。

【复现】先确认：
```

npm run build
node dist/bin.js upgrade --help   # 应复现 Dynamic require of "tty" 错误
```

【调查】
1. 读 tsup.config.ts 看当前打包配置（format / platform / external / noExternal / banner 等）。
